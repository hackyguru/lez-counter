**LEZ Counter v0.1.0**: one number on the Logos Execution Zone testnet that everyone shares.

> [!WARNING]
> **Unofficial, experimental, testnet only.** Not an official Logos module. It talks to the public LEZ v0.3 testnet, whose LGO has no value and which can be reset.

### Packages (Basecamp 0.2.3)

| File | What it is |
|---|---|
| `logos-lezcounter_core-module-lib.lgx` | `lezcounter_core` core module (embedded LEZ wallet), macOS arm64 + Linux x86_64 |
| `logos-lezcounter-module.lgx` | `lezcounter` UI, macOS arm64 + Linux x86_64 |
| `*-darwin-arm64.lgx`, `*-linux-amd64.lgx` | The same modules, one platform per file |

Install the core first, then the UI, from **Modules → Install LGX Package**.

### What's in it
- A counter program deployed on the LEZ v0.3 testnet at `5ShXhcA9R972B2BgbomP2Qi3JM1gxGw7Yf5NHwA1fvv4`. Every install reads and bumps the same number.
- **+1 / +5** buttons, a live feed of everyone's increments, and a Details view. Gas comes from the testnet faucet automatically.
- `verify.sh` reads the counter straight from the sequencer, so you can check the module against the chain.

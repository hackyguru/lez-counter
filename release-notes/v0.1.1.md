**LEZ Counter v0.1.1**: points at the counter program redeployed after the LEZ testnet reset.

> [!WARNING]
> **Unofficial, experimental, testnet only.** Not an official Logos module. It talks to the public LEZ v0.3 testnet, whose LGO has no value and which can be reset.

### Changes
- The testnet reset wiped the v0.1.0 deployment. The same `counter.bin` (image id `4316d160…`) is redeployed at `473ERB4qt4as8KUbAvc9gm6hWxb6Mt7q3eANnsNLx4MN`, and the core now uses that address by default.
- The counter starts again from 0. Its account is `FkVJaxkLU7mWmndxVQoKjVE2e34wWBwoXUxdcynSNYcw`.
- `verify.sh` and the README point at the new deployment.

### Packages

| File | What it is |
|---|---|
| `logos-lezcounter_core-module-lib.lgx` | `lezcounter_core` core module (embedded LEZ wallet), macOS arm64 + Linux x86_64 |
| `logos-lezcounter-module.lgx` | `lezcounter` UI, macOS arm64 + Linux x86_64 |
| `*-darwin-arm64.lgx`, `*-linux-amd64.lgx` | The same modules, one platform per file |

Install the core first, then the UI, from **Package Manager → Install Local Package**. Already on v0.1.0? Paste the new address into **Details → Use a different deployment** instead.

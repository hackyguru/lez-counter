**LEZ Counter v0.1.2**: fixes the "Use a different deployment" field.

> [!WARNING]
> **Unofficial, experimental, testnet only.** Not an official Logos module. It talks to the public LEZ v0.3 testnet, whose LGO has no value and which can be reset.

### Fixes
- **Details → Use a different deployment** now keeps what you type or paste. In v0.1.0 and v0.1.1 the field was bound to the module's state, which the UI refreshes every second, so each refresh cleared it.

### Packages

| File | What it is |
|---|---|
| `logos-lezcounter_core-module-lib.lgx` | `lezcounter_core` core module (embedded LEZ wallet), macOS arm64 + Linux x86_64 |
| `logos-lezcounter-module.lgx` | `lezcounter` UI, macOS arm64 + Linux x86_64 |
| `*-darwin-arm64.lgx`, `*-linux-amd64.lgx` | The same modules, one platform per file |

Install the core first, then the UI, from **Package Manager → Install Local Package**. The counter program is unchanged: `473ERB4qt4as8KUbAvc9gm6hWxb6Mt7q3eANnsNLx4MN`.
